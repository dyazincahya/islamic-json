# Manners Dataset

Dataset bilingual Indonesia–Inggris tentang adab keseharian berbasis prinsip Al-Qur’an.

## Files

- `eating.json` — adab makan dan berbagi makanan.
- `sleeping.json` — istirahat, privasi, dan tanggung jawab.
- `mosque.json` — kebersihan, ketenangan, dan penghormatan di masjid.
- `travelling.json` — tujuan, persiapan, keselamatan, dan penghormatan saat bepergian.
- `visiting.json` — izin, waktu, privasi, dan kebaikan saat berkunjung.
- `social.json` — salam, ucapan, informasi, keadilan, dan hubungan sosial.

## Schema

Setiap file berisi array objek dengan `id`, `order`, `title`, `description`, `category`, dan `sources`. `title` dan `description` masing-masing memiliki nilai bahasa Indonesia (`id`) dan Inggris (`en`).

## Notes

Dataset ini adalah panduan umum yang developer-friendly, bukan kumpulan hadis atau fatwa. Penerapan rinci tetap mempertimbangkan keadaan, hak orang lain, keselamatan, aksesibilitas, aturan pengelola, dan hukum setempat yang sah.
