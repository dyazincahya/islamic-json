# Islamic Guides

`guides/` berisi panduan belajar dan tata cara ibadah—konten yang menjawab “bagaimana melakukannya”, bukan sekadar daftar atau ringkasan informasi.

- `pillars-of-islam/` — pengantar lima rukun Islam.
- `prayer/` — urutan gerakan dan bacaan salat.
- `purification/` — panduan wudu, tayamum, mandi wajib, dan bersuci.
- `pilgrimage/` — panduan haji dan umrah.
- `zakat/` — panduan zakat fitrah dan zakat harta.
- `fasting/` — panduan mengganti puasa Ramadan.
- `prayer/` — salat wajib, sunah, dan salat Id.
- `daily-worship/` — panduan memakai koleksi dzikir dan doa.
- `funeral/` — panduan salat jenazah.
- `learning/` — jalur belajar Islam dan Asmaul Husna.
- `quran/` — panduan memulai membaca Al-Qur'an.

Topik baru seperti haji dan umrah dapat ditambahkan sebagai `guides/pilgrimage/` dengan panduan terpisah untuk masing-masing ibadah. Panduan sebaiknya merujuk ke koleksi di `library/` jika perlu menampilkan bacaan atau data yang sudah tersedia, bukan menyalinnya.

Gunakan format bilingual Indonesia–Inggris yang dijelaskan pada README setiap dataset. Daftar lengkap endpoint ada di [`../catalog.json`](../catalog.json), dengan validasi melalui [`../catalog.schema.json`](../catalog.schema.json).
