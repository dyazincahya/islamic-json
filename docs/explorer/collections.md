# Koleksi

Portal build menyalin collection indexes dari `data/v2/indexes/`. Gunakan endpoint tersebut untuk menemukan item dan memuat path detailnya. Explorer filter interaktif akan menampilkan tipe, tahap, status, group, dan tag musiman dari index.

Endpoint umum:

- `data/v2/indexes/lessons.json`
- `data/v2/indexes/practices.json`
- `data/v2/indexes/supplications.json`
- `data/v2/indexes/sequences.json`
- `data/v2/indexes/glossary.json`
