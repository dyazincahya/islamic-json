# Journey tujuh tahap

`data/v2/stages.json` mendeklarasikan tujuh tahap pembelajaran secara berurutan, goal lokal, entry content, dan anggota konten. Quran memiliki journey adaptif menurut kemampuan baca; portal tidak memaksa semua pengguna memulai dari Iqra.

Gunakan `stage.contentIds` dan index stage yang dideklarasikan setiap stage untuk visualisasi navigasi.
