# Registry

Manifest menunjuk registry untuk sumber, icon, dan feature links. Referensikan ID registry dari konten; jangan menyalin metadata sumber atau provider ke setiap item.

- **Sources:** bibliografi dan locator.
- **Icons:** semantic icon ID, provider mapping, lisensi, dan optional SVG.
- **Features:** sambungan ke kemampuan aplikasi seperti audio, pengingat, atau bookmark.

Icon wajib memiliki fallback yang dapat diakses. Jika SVG gagal tersedia, tampilkan label teks semantic icon.
